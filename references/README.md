# External reference code

`balsam-eval/` is a source snapshot of the [KSAA BALSAM evaluation service](https://github.com/ksaa-nlp/balsam-eval) at commit `a7f38208ed6b3817bf40ec324c4cb8acbbbeee9f` (retrieved 2026-09-25). Its original Apache-2.0 license is preserved in `balsam-eval/LICENSE`.

This copy is for studying BALSAM task formatting and scoring. Barq does not import or run it as part of its pipeline. The upstream repository contains evaluation code, not the complete BALSAM development or test datasets.
